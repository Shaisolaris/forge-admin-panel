# Forge Admin

Admin panel with data tables, user management, and full CRUD flows.

**[Live Demo](https://shaisolaris.github.io/forge-admin-panel/)**

## Features

- Paginated, searchable data tables
- User management with role badges and status toggles
- Create/edit/delete flows with confirmation states
- Filter and bulk-action patterns

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
